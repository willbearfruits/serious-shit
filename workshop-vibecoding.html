Vibecoding for Artists

Code your ideas, let AI write the syntax

Use AI (Claude / ChatGPT) as your code collaborator to build sound + visual pieces that run in the browser. From canvas sketches to a deployed URL you can share. No coding background required.

Duration: 6 meetings × 2.5 hours Participants: Up to 8 Location: MEZO Haifa, Sirkin 3 Prerequisites: None

Target: Artists, designers, musicians, anyone curious about making web-based pieces with AI assistance. Requirements: Laptop + AI subscription (~$20/month) + headphones.

Claude / ChatGPT Web Audio Canvas JavaScript GitHub Pages
Includes: 4 hours/week open-lab access at MEZO Haifa (3D printers, CNC, soldering, component library). No physical kit — bring your laptop.

Meeting Breakdown

1

Setup & First Canvas Sketch

  • Editor setup (VSCode + Cursor, or Claude.ai with artifacts)
  • How to talk to AI for code: prompts that actually work
  • Hello world in the browser, drawing shapes on HTML5 Canvas
  • Your first generative sketch

Takeaway: A working dev setup and your first running canvas piece.

2

Web Audio Basics

  • The Web Audio API mental model: nodes and graphs
  • Oscillators, gain, envelopes
  • Your first browser synth, scaffolded with AI
  • Parameter control with simple UI

Takeaway: A playable web synth you can iterate on.

3

Generative Visuals

  • Time-based animation loops
  • Particle systems, noise functions, simple physics
  • Color, composition, intentional aesthetic choices
  • Saving + reloading sketches

Takeaway: A toolkit of visual patterns you can compose.

4

Reactive Pieces

  • FFT and audio analysis in the browser
  • Wire microphone or audio file into visual parameters
  • Cross-modal feedback (visual reacts to sound and back)
  • Performance considerations

Takeaway: An audio-reactive visual piece.

5

Inputs & Interactivity

  • Keyboard, mouse, touch events
  • Microphone and webcam as input
  • Designing an instrument: what gestures map to what sounds
  • Saving presets

Takeaway: A playable interactive piece, not just a fixed sketch.

6

Deploy

  • Git basics with AI handling the syntax
  • Publish to GitHub Pages — a real URL anyone can open
  • Sharing, documenting, embedding in a portfolio
  • Group showcase

Takeaway: A deployed piece with a public URL — and the knowledge to ship the next one solo.

וייבקודינג לאמנים

לקודד רעיונות, לתת ל-AI לכתוב את הסינטקס

שימוש ב-AI (Claude / ChatGPT) ככלי עזר לכתיבת קוד, לבנייה של יצירות צליל וויזואל שרצות בדפדפן. מסקיצות קנבס ועד URL פומבי שאפשר לשתף. אין צורך ברקע בתכנות.

משך: 6 מפגשים × 2.5 שעות משתתפים: עד 8 מיקום: מזו חיפה, סירקין 3 דרישות קדם: אין

קהל יעד: אמנים, מעצבים, מוזיקאים — כל מי שרוצה ליצור עבודות מבוססות דפדפן בעזרת AI. דרישות: מחשב נייד, מנוי AI (~20$/חודש) ואוזניות.

Claude / ChatGPT Web Audio Canvas JavaScript GitHub Pages
כולל: 4 שעות/שבוע גישה למעבדה פתוחה במזו חיפה (מדפסות 3D, CNC, הלחמה, ספריית רכיבים). אין ערכה פיזית — להביא מחשב.

פירוט המפגשים

1

הגדרה וסקיצת קנבס ראשונה

  • הגדרת סביבת פיתוח (VSCode + Cursor, או Claude.ai)
  • איך מדברים עם AI לקבלת קוד שעובד: פרומפטים יעילים
  • Hello world בדפדפן, ציור צורות על HTML5 Canvas
  • סקיצה גנרטיבית ראשונה

תוצר: סביבת פיתוח עובדת ויצירת קנבס ראשונה.

2

יסודות Web Audio

  • המודל המנטלי של Web Audio API: צמתים וגרפים
  • אוסילטורים, גיין, מעטפות
  • סינת' דפדפן ראשון בעזרת AI
  • שליטה בפרמטרים דרך UI פשוט

תוצר: סינתיסייזר דפדפן ניתן לנגינה.

3

ויזואל גנרטיבי

  • לולאות אנימציה מבוססות זמן
  • מערכות חלקיקים, פונקציות רעש, פיזיקה פשוטה
  • צבע, קומפוזיציה, בחירות אסתטיות מודעות
  • שמירה וטעינה של סקיצות

תוצר: ארגז כלים של דפוסים ויזואליים שניתן לחבר.

4

יצירות ריאקטיביות

  • FFT וניתוח אודיו בדפדפן
  • חיבור מיקרופון או קובץ אודיו לפרמטרים ויזואליים
  • פידבק חוצה-מדיה (ויזואל מגיב לסאונד וההפך)
  • שיקולי ביצועים

תוצר: יצירה ויזואלית שמגיבה לאודיו.

5

קלטים ואינטראקטיביות

  • מקלדת, עכבר, אירועי מגע
  • מיקרופון ומצלמה כקלט
  • עיצוב כלי: אילו מחוות מפעילות אילו צלילים
  • שמירת preset-ים

תוצר: יצירה אינטראקטיבית ולא סקיצה קבועה.

6

פרסום

  • יסודות Git עם AI שמטפל בסינטקס
  • פרסום ב-GitHub Pages — URL ציבורי לכל אחד
  • שיתוף, תיעוד, הטמעה בפורטפוליו
  • תצוגה קבוצתית

תוצר: יצירה מפורסמת עם URL פומבי — והיכולת לעשות זאת שוב לבד.
